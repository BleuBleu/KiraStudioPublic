# Demo Song SoundFonts

This page provides direct download links to the SoundFonts required to listen to some of the [demo songs](thanks.md#demo-songs).

## Download Links

### SGM V2.01

This one is required for the **Ruder Buster**, **Cold Brew**, the **Duality** album and maybe a few others. You can choose between two versions: 

- [SGM V2.01.sf3 (27 MB)](../../soundfonts/SGM-V2.01.sf3) : OGG/Vorbis compressed version. Much smaller, fast download directly from this website. Recommended.
- [SGM V2.01.sf2 (235 MB)](https://archive.org/download/SGM-V2.01) : Original version. Slightly higher quality, but much larger. Download from archive.org is usually very slow.

## Loading the SoundFonts in the Demo Songs

To load the SoundFonts in the demo songs:

1. Locate a channel using one of the missing SoundFonts. SoundFont channels have a **A&#8203;_A_** icon. 
	* On desktop, click on the channel name to show its settings in the Project Explorer.
	* On Mobile, double-tap on the channel name and the Project Explorer will appear.
2. In the Project Explorer, under the SoundFont generator settings, look for a red warning sign next to the SoundFont name and click it. 
3. Locate the requested SoundFont on your device.
4. Once you fix one channel, it will fix all the other channels using this SoundFont. Also, once you tell KiraStudio where a SoundFont is located, it will remember it forever and not ask you again.
